# Kotteri101 Studio — website

Static site for kotteri101.studio (homepage + per-app privacy policies). No app source code lives here — the apps themselves stay in their own private repositories:

- `index.html` — studio homepage
- `worklock/privacy.html` — WorKlock privacy policy (draft, not yet linked from App Store Connect)
- `golden-ear/privacy.html` — Golden Ear privacy policy
- `hearing-check/privacy.html` — Hearing Check privacy policy

GitHub Pages is currently **off** for this repo. Turn it on (Settings → Pages) when ready to go live, then point the `kotteri101.studio` custom domain here.
